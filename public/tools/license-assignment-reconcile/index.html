License Assignment Reconcile

Compare expected and observed Microsoft 365 user/SKU pairs for a human review handoff.

No permissions required. Browser-local processing · no upload · no tenant connection.

Compare assignment lists

Open a UTF-8 CSV or paste one on each side. Required headers: UserPrincipalName,SkuId (case-insensitive). One pair per row; no extra columns. Both inputs need at least one assignment. Maximum 1 MiB and 5,000 assignment rows per input.

This acknowledgement is not tenant verification. Use the same SKU identifiers in both lists: exact GUIDs or case-sensitive SKU part numbers. GUIDs and part numbers are not mapped to each other.

Add both assignment lists and confirm the same tenant and scope.

CSV schema and synthetic example

Example only — synthetic identities, not production data. Header order may be reversed. RFC4180 quoted fields, an optional UTF-8 BOM and CRLF or LF line endings are accepted. Blank rows, extra columns and control characters in fields are rejected.

UserPrincipalName,SkuId
alex@example.com,SPE_E3

UPNs are trimmed and lowercased. Supported identities are ASCII, at most 254 characters, with a local name up to 64 characters using letters, digits, apostrophe, ! # ^ ~ _ - and single separating dots. The domain needs at least two valid dot-separated labels. Non-ASCII identities are unsupported. SKUs are not trimmed: use an exact GUID without braces or padding, or letters, digits, underscores and hyphens. GUID-shaped values must contain valid hexadecimal digits. Part-number case is preserved.

Download handoff

JSON includes both normalized lists, duplicate counts and all comparison rows. CSV includes all comparison rows, regardless of the display filter. Downloads contain user identities; handle them as internal information.

CSV quotes every cell and prefixes formula-leading values with an apostrophe. Use JSON when exact normalized identifiers are needed; the CSV is a review handoff, not a round-trip input or tenant import.

Permissions, custody and limits

No Graph permissions, OAuth, admin consent, API or Microsoft 365 license is needed for local use. Obtaining customer-authorized assignment exports is separate and outside this tool.

Inputs and results remain in page memory. No content network requests, storage, analytics, dependencies or authentication. Static hosting receives ordinary page and asset request metadata. Only the two required columns are accepted; unrelated columns are rejected, not retained. Duplicate pairs use set semantics with counts disclosed.

Clear or reload discards the page’s inputs and results; it does not delete original files or earlier downloads and does not guarantee heap erasure. This tool neither verifies tenant/scope nor reads or writes a tenant, and provides no tenant rollback. Partial or inconsistent source inventories can produce misleading differences: review acquisition scope and timing separately.
