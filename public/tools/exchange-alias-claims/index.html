Scope, limits and data handling

What each flag means

  • current-other-owner conflict: another GUID holds the address in supplied current evidence.
  • multiple-request-owner conflict: different GUIDs request the same address. Repeated rows for one GUID are not competing owners.
  • current-same-owner: the requesting GUID already holds the address in supplied current evidence.
  • not seen in supplied current list: there is no matching current address in this evidence; it is not an availability decision.

Evidence limits

Deleted, hidden, hybrid, mail-enabled public folder (MEPF), Entra-only and unexported recipients may be absent. Stale or incomplete exports do not establish tenant-wide coverage. Include every relevant recipient type you are authorized to inventory, including groups. This tool does not assess primary SMTP, accepted domains, policies, deliverability or transfer ordering.

Exact 8-4-4-4-12 hexadecimal GUIDs only, normalized to lowercase. Address length ≤254 characters; local part ≤64; dotted ASCII DNS labels ≤63 each, no edge hyphens. Common dot-atom punctuation is accepted, but leading, trailing or consecutive local-part dots are not. Unsupported syntax is rejected rather than guessed. CSV permits quoted cells, an optional UTF-8 BOM, LF or CRLF, and one final line ending. Blank rows, extra columns, controls and malformed quoting are rejected. File decoding is fatal on invalid UTF-8.

Each input: 1 MiB and 5000 data rows maximum, counting duplicates. Duplicate normalized recipient/address pairs count once and are disclosed. Reviews exceeding 50000 related owner references are blocked before results or downloads; this counts existing and requesting owner references across unique requested rows.

Custody and authority

No permissions, admin consent, authentication, API access or Microsoft 365 license is required for this local comparison. Obtaining the original inventory requires separate customer authority and may have its own access requirements. No tenant reads, writes, execution scripts or rollback actions are supplied.

No analytics or browser storage. Content stays in page memory; no content network destinations. Static hosting receives ordinary page and asset request metadata. Editing either input or the identity confirmation discards the review and disables exports. Clear removes page inputs, selected files and review memory, not original files or previous downloads. Reload or closing the page also discards the working state.
