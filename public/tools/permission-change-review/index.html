        Permissions, limits and data handling

        No OAuth, admin consent, APIs or license are needed for this local comparison. Obtaining authorized manifests is outside this tool. Scope is delegated configuration. Role is application configuration and requires heightened human review.

        Inputs and notes remain in this page’s memory. No storage persistence, analytics, uploads, remote fonts or content network destinations. Static hosting receives ordinary page and asset request metadata. Unknown manifest fields, including credentials, are discarded from the packet.

        Clear or reload discards the page’s inputs and review, not original files or earlier downloads. Each input supports up to 200 resource blocks and 2,000 permission entries; reasons support up to 2,000 characters. Duplicate tuples use set semantics and are disclosed. This is not effective-access analysis and performs no tenant reads, writes, grant revocation or rollback.
